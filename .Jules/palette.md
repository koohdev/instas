## 2024-08-09 - Missing ARIA Labels on Navigation Arrows
**Learning:** Icon-only navigation buttons (like chevron left/right for calendars and slides) frequently miss accessible labels, which makes screen readers unable to convey their purpose to visually impaired users. Even when tooltips or surrounding context exist, explicit aria-labels on interactive elements are necessary for proper navigation flow.
**Action:** Always add descriptive `aria-label`s to `<Button>` components that rely solely on icons to convey their action (e.g., `aria-label="Previous month"`, `aria-label="Next slide"`).
## 2025-03-05 - Enhancing Safety and Scalability in SaaS Interfaces
**Learning:** V1 applications often prioritize core functionality over edge-case UX, leading to destructive actions without confirmation, silent validation failures, and UI components that break at scale (like overcrowded filter pills or rendering massive lists). Furthermore, long-running batch processes need user controls like cancel or pause to avoid forcing hard refreshes.
**Action:** Implemented confirmation dialogues before deletion actions, enforced URL validation to prevent invalid queue entries, introduced pagination and horizontal scrolling to handle large data sets gracefully, and added an abort mechanism for batch processing queues. Additionally, ensured all newly added icon-only buttons include descriptive `aria-label` attributes.
